# Współtworzenie KsefPrinter

Dziękujemy za zgłoszenia i poprawki.

- Przed zgłoszeniem błędu sprawdź, czy problem nie został już opisany.
- Podaj wersję aplikacji, system Windows i kroki odtworzenia problemu.
- Nie załączaj rzeczywistych faktur, numerów KSeF, danych klientów ani danych uwierzytelniających.
- Do testów używaj wyłącznie danych syntetycznych.
- Zmiany proponuj w osobnej gałęzi i przez Pull Request; opisz zakres i sposób testowania.
- Zachowaj informacje o autorstwie i link do oryginalnego repozytorium zgodnie z [NOTICE.md](NOTICE.md).
- Wnosząc kod, potwierdzasz, że możesz go udostępnić na warunkach licencji projektu.
