# Zgłaszanie problemów bezpieczeństwa

Nie publikuj szczegółów podatności ani rzeczywistych faktur w publicznych Issues.

Zgłaszaj podatności prywatnie przez GitHub Security Advisories (zakładka Security → Report a vulnerability), jeśli ta funkcja jest dostępna. W przeciwnym razie skontaktuj się z właścicielem repozytorium prywatnym kanałem.

Nie dołączaj danych klientów, kluczy ani haseł. Nie ma obecnie gwarantowanego terminu reakcji.
